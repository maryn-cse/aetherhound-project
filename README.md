# AetherHound – Air-Gapped Signal Anomaly Detection

**Cybersecurity Internship Project | Infotact**

## About the Project

AetherHound is a cybersecurity project focused on detecting unusual acoustic and Radio Frequency (RF) signal patterns around air-gapped systems.

## Project Objectives

- Monitor acoustic and RF signals.
- Analyze signal patterns using Digital Signal Processing (DSP).
- Identify unusual signal activity.
- Generate alerts for detected anomalies.

## Key Features

- Acoustic signal monitoring
- RF signal analysis
- Signal visualization
- Anomaly detection
- Event logging

## Technologies Used

- Python
- NumPy
- SciPy
- SoundDevice
- SoundFile
- Matplotlib
- GNU Radio (planned)
- TensorFlow / PyTorch (planned)
